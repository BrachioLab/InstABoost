# InstABoost: Instruction Following by Principled Attention Boosting

Anonymized code release for the paper *Instruction Following by Principled Attention
Boosting*, submitted for review. Author and institution information has been removed
from this repository.

InstABoost steers a transformer by adding a fixed positive bias to the pre-softmax attention
logits of instruction tokens, so that the model attends more to the instruction at every
generation step. The repository has two independent parts, one for each set of experiments in
the paper.

## Repository layout

| Directory | Contents | Status |
|---|---|---|
| `theory_experiments/` | Experiments on small learned reasoners that validate the theoretical analysis: attack sweeps vs. bias in replace and append mode, the coerce-state variance analysis, the boost trade-off, the subversion cost vs. bias, and attention to applicable vs. non-applicable rules on the clean model. Includes saved results and figures. | Included |
| `llm_experiments/` | Steering experiments on large language models (emotions, AI-risk personas, TriviaQA, TruthfulQA, safety, JailbreakBench, toxicity), the IFEval benchmark, the baselines (prompting, latent steering, Spotlight, PASTA/AutoPASTA), and the notebooks and scripts that aggregate results. | Included |

Each part has its own README with setup and reproduction commands, its own `requirements.txt`,
and its own `results/` directory with the CSVs and figures reported in the paper.

## Theory experiments

`theory_experiments/` builds on the public [`tf_logic`](https://github.com/AntonXue/tf_logic) code base for learned
propositional reasoners, the code release of the prior work on logic-based attacks that the
theory section extends. It is not standalone: the runners import the
models, datasets, and checkpoints from that repository and import themselves as the package
`instaboost_theory_exp`. To run them, copy or symlink this directory into the `tf_logic`
repository root under that name:

```bash
git clone https://github.com/AntonXue/tf_logic.git tf_logic
ln -s "$(pwd)/theory_experiments" tf_logic/instaboost_theory_exp
cd tf_logic
pip install -r instaboost_theory_exp/requirements.txt
```

See `theory_experiments/README.md` for the experiment list, checkpoints, and commands. The
runs use a single-layer GPT-2 reasoner and execute on CPU; sweeps are resumable, since runners
skip rows already present in their output CSV.

## LLM experiments

`llm_experiments/` is standalone. It runs on GPU inside a CUDA PyTorch container, downloads
all datasets on first use, and needs a Hugging Face token for gated models, a Gemini key for
the LLM judges, and a Perspective API key for toxicity scoring, all read from the environment
or a `.env` file. See `llm_experiments/README.md` for the steering, IFEval, and PASTA
head-selection commands. Result directories are git-ignored and regenerated by the scripts.
